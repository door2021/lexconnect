# ADR-0003: Three-state lawyer verification
Status: Accepted
Decision: License number is optional at signup. No admission = Unverified;
submitted = Pending; admin-confirmed = Verified (badge). Verification is
per BarAdmission. Unique license enforced only among verified admissions.
DMs and referrals require Verified.
Why: a typed number is a claim, not proof; the badge is the platform's trust promise.
Rejected: auto-verify on submission (trivially spoofable).
